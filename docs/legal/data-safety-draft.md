# Google Play Data Safety: Draft Answers

Draft answers for the Play Console Data Safety form, kept consistent with
[the privacy policy](privacy-policy.md). Answers tagged **[HT-56]** depend on
the final HT-56 (Sentry diagnostics) implementation and must be re-checked
against the merged code before submission.

## Data collection and security

- Does your app collect or share any of the required user data types? **Yes**
  (crash logs and diagnostics only). **[HT-56]**
- Is all of the user data collected by your app encrypted in transit? **Yes**
  (Sentry ingestion is HTTPS only). **[HT-56]**
- Do you provide a way for users to request that their data is deleted?
  **Yes**: by email to [support email]; no accounts exist, so there is no
  in-app deletion.
- Account creation: **My app does not allow users to create an account**.

## Data types

- Location (approximate or precise): **Not collected**.
- Personal info (name, email, user IDs, address, phone, and others): **Not
  collected**. **[HT-56]** (relies on `beforeSend` clearing the Sentry user
  and `sendDefaultPii: false`)
- Financial info: **Not collected**.
- Health and fitness: **Not collected**.
- Messages: **Not collected**.
- Photos and videos: **Not collected**. **[HT-56]** (screenshots off)
- Audio files: **Not collected**.
- Files and docs: **Not collected**. (The match report attachment is game
  state generated by the app, declared under diagnostics, not a user file.)
- Calendar: **Not collected**.
- Contacts: **Not collected**.
- App interactions: **Not collected**. (No analytics; recent app-event
  breadcrumbs are part of the crash diagnostics.) **[HT-56]**
- In-app search history: **Not collected**.
- Installed apps: **Not collected**.
- Other user-generated content: **Not collected**.
- Other actions: **Not collected**.
- Web browsing history: **Not collected**.
- App info and performance > Crash logs: **Collected**. **[HT-56]**
- App info and performance > Diagnostics: **Collected** (device model, OS
  version, app version, technical state, match report attachment).
  **[HT-56]**
- App info and performance > Other app performance data: **Not collected**
  (no sessions or performance traces). **[HT-56]**
- Device or other IDs: **Not collected**. **[HT-56]** (relies on `beforeSend`
  clearing the device unique identifier and the user, which also removes
  Sentry's installation ID; re-check a real event in Sentry to confirm no
  `user.id` or device ID survives)

## For each collected type (Crash logs, Diagnostics)

- Collected, shared, or both? **Collected only.** Sentry acts as a service
  provider processing data on our behalf, which Play does not count as
  sharing.
- Is this data processed ephemerally? **No** (stored in Sentry for the
  retention period).
- Is collection required or can users choose? **Users can choose**: opt-out,
  default on, disclosed at first run and in Settings > Privacy. **[HT-56]**
- Why is this data collected? **App functionality** (finding and fixing bugs
  and crashes). Not analytics, advertising, personalization, fraud
  prevention, or account management.

## Other declarations (outside the Data Safety form)

- Ads: **No, my app does not contain ads**.
- Advertising ID: **Not used**; the app does not declare the

  merged library manifests, has no `com.google.android.gms.permission.AD_ID`)
- Target audience: **13+ / general**, not "Designed for Families".
