# Security Policy

## Supported versions

Hareeg Table is in early development. Security fixes are applied to the latest
`main` and the most recent release only.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report privately instead:

- Preferred: open a [private security advisory](https://github.com/Maiz27/hareeg-table/security/advisories/new)
  via GitHub's "Report a vulnerability" button.
- Alternative: email **magedfaiz98@gmail.com** with the details.

When reporting, include:

- A description of the issue and its impact.
- Steps to reproduce, or a proof of concept.
- The affected version, platform, and build (debug/release) if known.

## What to expect

- An acknowledgement within a few days.
- An assessment of severity and a fix plan, shared with you as it develops.
- Credit in the release notes once a fix ships, unless you ask to stay anonymous.

## Scope notes

Hareeg Table is an offline-first game. It has no backend and no account system.
The only data that can leave the device is a bug/crash report the player chooses
to send. Reports about that flow — what it collects and when — are in scope and
welcome.
