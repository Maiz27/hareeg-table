# Brand Assets

This folder stores source brand artwork and icon concepts for Hareeg Table.

## App Icon Concept v2

`app-icon-concept-v2.png` is the selected app icon direction: dark felt table,
fanned cards, warm flame, and a subtle Fifty token. Treat it as source concept
art for now, not final generated Android launcher assets.

## Sandline Joker Launcher

`launcher/` contains the production Sandline Lounge launcher icon sources:
foreground, background, composite fallback, monochrome themed icon, and mask
preview. Regenerate them with:

```powershell
python scripts\prepare_sandline_icon.py <generated-joker-emblem-source>
```
